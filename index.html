HostsEditor

macOS 上的 Hosts 文件编辑与方案切换工具。在多套 hosts 配置之间稳定切换，通过特权 Helper 安全写回 /etc/hosts。 A hosts file editor and profile switcher for macOS. Switch between multiple hosts setups reliably, and write /etc/hosts safely through a privileged helper.

工作方式How it works

应用管理的内容写成带标记的块，多个启用方案可以组合写入，原始基础内容保持不变。Managed content is written as marked blocks, so several enabled profiles combine while your original base content stays intact.

127.0.0.1        localhost

# HostsEditor:BEGIN:<profile-id>
127.0.0.1        api.example.dev
# HostsEditor:END:<profile-id>

安装Install

不确定芯片类型？打开「苹果菜单 › 关于本机」，看“芯片”或“处理器”一栏。Not sure which chip you have? Open › About This Mac and check “Chip” or “Processor”.

  1. 下载与本机芯片匹配的 DMG，打开后把 HostsEditor 拖进「应用程序」文件夹。Download the DMG for your chip, open it and drag HostsEditor into Applications.
  2. 打开 HostsEditor。首次读取或写入系统 hosts 时，应用会注册特权 Helper，按系统提示输入管理员密码。Launch HostsEditor. The first time it reads or writes the system hosts file it registers a privileged helper; enter your administrator password when asked.
  3. 如果出现“需要允许后台程序”，前往「系统设置 › 通用 › 登录项与扩展程序」允许 HostsEditor 的后台程序，然后重新打开应用。If macOS asks to allow a background item, go to System Settings › General › Login Items & Extensions, allow HostsEditor, then reopen the app.
  4. 点击左下角「新建」创建本地方案或远程方案，勾选即启用，⌘S 保存并应用。Click “New” to create a local or remote profile, tick it to enable, and press ⌘S to save and apply.
