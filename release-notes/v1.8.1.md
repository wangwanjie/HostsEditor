# 更新内容

- 修复在「系统」项中编辑 hosts 后，切换到其他方案、或在后台启用 / 停用方案时，未保存的编辑被静默覆盖的问题；切回「系统」项会恢复编辑内容，点击「刷新」前会先确认。
- 修复远程方案或导入文件使用 Windows 换行（CRLF）时，写入系统 hosts 后对应条目不生效的问题。
- 「默认」项会随系统 hosts 的变化同步刷新。
- 新建本地方案后可直接输入名称；添加远程方案时自动填入剪贴板中的地址，按回车即可添加。
- 主窗口关闭后，使用「文件」菜单新建或导入方案会自动打开主窗口。
- 语法高亮覆盖同一行中的所有主机名别名；错误提示过长时可悬停查看完整内容。
- 修复「隐藏其他」与「隐藏」快捷键冲突（现为 ⌥⌘H），移除窗口菜单中无用的标签页选项。
